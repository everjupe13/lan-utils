# Рядом 0.2.0

- Добавлена проверка обновлений при ручном запуске приложения.
- Новая версия предлагается в стандартном диалоге macOS с описанием изменений.
- В окне управления и меню появилась кнопка проверки и установки обновлений.
- Архивы обновлений и сведения о версиях защищены подписью Ed25519.
- Перед установкой сервер штатно останавливается; после обновления приложение запускается снова.

Обновление перезапускает сервер и очищает чаты, партии и временные вложения. Настройки порта и лимитов сохраняются.
